### ⚠️ E2E 함정 모음
- 브라우저는 한 번만 띄우고, 옵션은 `args=["--disable-dev-shm-usage"]`, `service_workers="block"`, `device_scale_factor=1~2`.
- `page.goto(url, wait_until="domcontentloaded")` 사용 권장 (외부 구글 폰트 CDN 지연 방지).
- 세이브 주입은 `add_init_script` + sessionStorage 가드. 가드가 없으면 새로고침할 때마다 다시 주입됨.
  - localStorage 키: `magic_academy_astra_save_v1`
  - 세이브 넣을 때 `lastSavedAt=now`로 설정 (안 하면 오프라인 보상 모달이 뜸)
- `pagehide` 시 자동 저장되므로, 오프라인 보상 테스트는 기존 `page.close()` 후 새 페이지 `add_init_script`로 `lastSavedAt`를 과거로 되돌려야 덮어씌워지지 않음 (`page.reload()`는 장시간 세션 후 헤드리스 크로미움 크래시 주의).
- 자동 저장은 8초마다. localStorage를 읽으려면 8.6초 이상 기다릴 것.
- 셀렉터:
  - 토스트 `.toast-float`
  - 스토리 모달 `.story-vn-modal`, 닫기 `button.btn-gold`
  - 내비 `.bottom-nav button` (0 전투 · 1 학교 · 2 덱 · 3 사역마 · 4 심연)
  - 마도구 서브탭은 텍스트 "마도구"
  - 막 스토리 버튼 `button[title='막 스토리']`
  - 몬스터 카드 `.enemy-card .portrait-frame`
- 자동 전진이 ON이면 1-4를 깨자마자 보스로 넘어감. 일반몹 화면을 찍으려면 `settings.autoAdvance=False`, `selectedStage=1`.
- 모달(`.modal-backdrop`)이 떠 있으면 내비 클릭이 막힘. 먼저 닫을 것.

## 6. 막혔을 때 참고 메모

- 플레이어 HP는 매 전투 리셋됨.
- 덱은 "쓸 수 있는 첫 스킬"을 시전함. 그래서 시작 키트 순서가 [누킹 cd2, 보호막, 필러 cd0].
- 보호막은 보스 강공격을 하드카운터함 (의도된 설계).
- 3막부터 난이도 램프 `ACT_RAMP {perAct:1.5, atkShare:0.6}`. ×1.65 / ×1.8은 이미 반려됨.
- 일반몹 공격 ×3은 반려 (Lv1이 계속 죽음).
- 스토리:
  - `STORY_GAP_MS = 25_000`. 도입/중반은 대기열, 보스/클리어/승급은 즉시 표시.
  - 자동 보스 도전은 대기 중인 스토리가 다 나올 때까지 기다림.
- UI:
  - 몬스터 카드 원화는 `mix-blend-mode: multiply`로 양피지에 녹임.
  - 리스트는 inline 글자색 때문에 **어두운 가죽 카드**, 대사/소개만 양피지.
